# When to disclose AI use

This guide explains when and how to disclose artificial intelligence tools in scholarly manuscripts.

## Kinds of AI use

Scholarly publishing policies distinguish between several distinct categories of AI assistance:

- `none`: No artificial intelligence tools were used in writing, data processing, analysis, or image creation.
- `language_editing`: Tools were used solely to polish text, improve readability, or assist with non-substantive grammar and syntax editing.
- `generative_content`: Tools were used to generate draft prose, synthesize sections, produce figures, or draft abstracts.
- `research_conduct`: Tools were used in research design, data collection, statistical modeling, literature search automation, or code execution.

## Policy variations across venues

Policies differ significantly across publishers, societies, and institutions:
- Some venues permit language editing with standard acknowledgment, while strictly prohibiting generative text in core conceptual sections.
- Other venues permit generative text provided the prompts, tools, versions, and validation procedures are documented in detail in the Methods or Acknowledgments section.
- Many venues require specific declaration placement (e.g., a dedicated "Declaration of Generative AI" section before the references).

## Exemptions

Exemptions are set by each policy; there is no exemption that applies across policies. The Exemptions column of the table below lists the uses that each policy names as exempt, usually basic spelling, grammar or copy-editing tools; some policies list none.
- If the column is empty for your venue, disclose any AI use.
- If the column names an exemption, it covers only that use; anything beyond it is disclosed.
- Check the column instead of assuming an exemption, and confirm with the current policy.

When tools rephrase text substantively or generate content, disclosure is required.

## Authorship restrictions

An artificial intelligence tool or large language model cannot be credited as an author or co-author on any scholarly work. Authorship requires intellectual accountability, approval of final versions, and legal responsibility for scientific integrity, none of which an automated system can assume.

Always check the current guidelines of your target venue before submission.
