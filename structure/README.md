# Structure guidance

This directory is reserved for future, verified guidance by document type, discipline and section. It contains no guidance yet, on purpose: statements about how to structure a scholarly document are only added here once they are backed by official sources.

Today, structure recommendations come from `scripts/recommend.py`, which returns the required and recommended sections, the reporting guidelines that apply (with their official links and license caveats), and the reference style. See `SKILL.md`.
